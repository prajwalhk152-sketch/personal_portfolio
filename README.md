# Prajwal H K — Portfolio

A minimal responsive developer portfolio built for Prajwal H K, a BCA student and AI/ML enthusiast.

## Tech Stack

- React + Vite + JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Add project screenshots under `public/images/` using the named image paths in `src/App.jsx`. Add the resume as `public/resume/Prajwal_H_K_Resume.pdf`.

For Vercel, import the GitHub repository, select Vite, then deploy with `npm run build` and `dist` as output.
